# Jude interaction parity map

This is a browser comparison of the public Sable demo and Jude’s web app on 7 November 2026. Each side opened in fresh Chromium storage at **1440 × 900** and **390 × 844** CSS pixels. Jude’s workspace used a new synthetic guest on each viewport. The phone runs used Chromium touch emulation. Both sites used Indonesian. Measurements below describe rendered controls and scroll containers. [Hosted reference](https://vennethn.github.io/sable-mockup/)

## Following the same evidence

Start with the Gudang Cakung case. In Jude, `/demo` seeds an isolated workspace and redirects to its case-specific URL. The paths below use that entry point so the instructions work for another guest. Begin at hearing 2, jump to Rina at **00:14:32**, open the finding about arrival time, compare the gate log on page 7, then return to Rina’s BAP on page 4. The selected records should stay identifiable across pages, sheets and browser history.

## Motion and return checks

- Following a 650px wheel event on the hosted landing, the viewport had traveled about 128px at 15ms, 349px at 98ms and 639px at 598ms. Its six-paper desk remains pinned on tall phones. The other phone scenes use document flow. With reduced motion, the sources are readable at rest. [Landing](https://vennethn.github.io/sable-mockup/)
- Hosted page changes cross-fade the root for 220ms. Stable chrome stays in place. Controls use approximately 110ms for a press and 170ms for short state changes. On the floating navigation the transform takes 550ms and opacity 300ms. Test the halfway state as well as the settled state. [Hosted application](https://vennethn.github.io/sable-mockup/#/case/c1)
- Recheck the first-visit invite, per-document findings link, finding detail and pricing against the web-shell changes. Recheck the initial canvas against the board changes. For search and inspectors, verify keyboard entry, Escape, focus restoration, the 390px sheet and reduced motion. Keep simulated plan changes and sample-only hearing playback identified in the UI.
