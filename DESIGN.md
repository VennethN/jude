# The counsel table

The public cover feels like a closed case file. Inside, the working surface opens into an indexed reading room. Forest green anchors the navigation. Warm paper carries testimony and evidence. A wine-coloured annotation marks a matter requiring a lawyer’s attention.

## Typography and layout

Set the wordmark in Rufina, questions and case titles in Caslon Display, testimony in Manrope and filed extracts in Courier Prime. Align each document reference with its quote. A case starts with its most consequential open question. Place hearing and exhibit indexes below it. Use one broad reading column on a phone and a fixed, labelled navigation rail when there is room.

## Components

Text and shape accompany review status. A paper folio can carry a single prominent case or comparison. Ordinary lists use fine dividers. Dialogs have a visible close control, initial focus, Escape dismissal and a return focus target. Use motion only to orient navigation and selection. Preserve a fully static reduced-motion presentation.

## Night

Use deep green-grey paper with lighter text. Keep written sources and testimony typographically distinct in both themes, including high-contrast and coarse-pointer layouts.
